# K20_Portfolio_CNTT_20-04
## 1. Giới thiệu

Website Portfolio dùng để giới thiệu bản thân, các kỹ năng, dự án đã thực hiện và thông tin liên hệ. Giao diện được thiết kế đơn giản, dễ sử dụng.

## 2. Công nghệ sử dụng

- HTML5: Xây dựng cấu trúc trang web.
- CSS3: Thiết kế giao diện và màu sắc.
- Flexbox và Grid: Sắp xếp bố cục.
- Responsive Design: Tương thích với máy tính, máy tính bảng và điện thoại.

## 3. Cấu trúc thư mục

- `index.html`: Trang chủ của website.
- `css/style.css`: Tệp định dạng giao diện.
- `images/`: Thư mục lưu trữ hình ảnh.

## 4. Cách chạy

- Mở thư mục Portfolio bằng Visual Studio Code.
- Mở tệp `index.html` bằng trình duyệt.
- Hoặc sử dụng tiện ích Live Server để chạy website.
